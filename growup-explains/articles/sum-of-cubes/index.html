Why is the sum of cubes a perfect square?

A famous formula is easier to remember when you can see why it must be true.

GROWUP EXPLAINS·Nov 13, 2026·6 MIN READ
A SURPRISING IDENTITY
1³ + 2³ + ··· + n³
= (1 + 2 + ··· + n)²

Start with a few small cases

n = 11³ = 1 = 1²
n = 21³ + 2³ = 9 = 3²
n = 31³ + 2³ + 3³ = 36 = 6²
n = 41³ + 2³ + 3³ + 4³ = 100 = 10²

The numbers being squared—1, 3, 6, 10—are triangular numbers, the sums of the first few positive integers.

THE SUM-OF-CUBES IDENTITY1³ + 2³ + ··· + n³ = [n(n+1)/2]²

The secret is the difference between two squares

Let Tn = 1 + 2 + ··· + n = n(n+1)/2. Compare the square of one triangular number with the previous square:

Tn² − Tn−1² = n³

Why? Substitute the formulas:

Tn² − Tn−1²
= [n(n+1)/2]² − [n(n−1)/2]²
= (n²/4)[(n+1)² − (n−1)²]
= (n²/4) × 4n
= n³

This says something delightful: each new cube is exactly the amount needed to grow one triangular-number square into the next.

Now watch everything cancel

Add the difference-of-squares identity for k = 1, 2, ..., n:

(T₁² − T₀²)+ (T₂² − T₁²)+ ···+ (Tₙ² − Tₙ₋₁²)= Tₙ²

Every intermediate square appears once positively and once negatively. They cancel, leaving only Tn² (because T0 = 0). So the sum of the cubes must equal the square of the triangular number.

A way to remember it

∑
Say it in one sentence

“The sum of the first n cubes is the square of the sum of the first n counting numbers.”

Try it yourself

What is 1³ + 2³ + ··· + 10³?

First compute 1 + 2 + ··· + 10 = 55. Then square: 55² = 3,025.

What is the difference between (1 + ··· + 9)² and (1 + ··· + 8)²?

Exactly 9³ = 729, by the difference-of-squares identity.
